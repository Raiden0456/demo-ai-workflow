System map
1Shared rules

One rulebook, stored in the repo

  • CLAUDE.md for Claude Code, AGENTS.md for Codex and Copilot, REVIEW.md for every reviewer.
  • Architecture, coding and testing rules live once in docs/ and every tool reads them.
  • Arrives with git pull. Personal tweaks stay local and out of git.

2Guardrails

Limits the agent can't talk its way around

  • Permissions: safe commands run freely, commits ask first, secrets, push and merge are denied.
  • Hooks close the gaps, so cat .env is blocked even when Read is denied.
  • Every edited C# file is formatted automatically, so reviews skip style debates.

3Jira via MCP

Jira inside the conversation

5Ticket to code

From ticket to tested change, with a plan you approve

  • Claude pulls the ticket and turns acceptance criteria into a checklist.
  • It stops at a plan. Code and tests come only after a developer approves it.
  • One test per criterion, build and tests green, nothing committed for you.

6Review gate

Two checks before a person looks

  • CI builds with warnings as errors, checks formatting and runs every test.
  • An AI reviewer comments on each pull request. Claude, Copilot or none, one switch.
  • Every reviewer uses the same REVIEW.md, and developers run it locally first.

Stop 6
7Human approval

A person merges. Always.

  • Branch protection needs one approval and a green build before anything reaches master.
  • The AI never approves, merges or pushes. Settings deny it and GitHub enforces it.
  • Reviewers spend their time on design and risk, not on missing null checks.

8Automations, optional

Routine that should happen on its own

  • Claude covers work that needs thinking. n8n covers events: something changes, something else happens, with retries and approvals.
  • Tickets move across the board automatically and the team gets an update in Slack.
  • A PM finishes requirements in Notion, AI drafts the tickets, the PM approves in Slack, and only then they appear in Jira.

Not on day one. We add it once we see which routine is still manual.
